# AirPay Mobile

Aplicativo Android/Expo do AirPay para wallet self-custody, pagamentos online via Gateway, pagamentos OffAir, descoberta local, histórico, risco, blocklist e sincronização.

## Origem

Este repositório foi separado do monorepo AirPay em 2026-05-16 para deixar o ecossistema com fronteiras claras por produto.
